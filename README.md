# CrowdGatherGo

Marketing site for **CrowdGatherGo** — frugal, analytically-grounded solutions for congestion-free mass movement of people.

Three value propositions:

1. **Long-distance rail throughput** — slot-based timetables that fit 500 daily trains on existing tracks at 5-minute headway, with overtakes at station loop lines.
2. **Easing city interchanges** — small, surgical junction redesigns (U-turn pairs, butterfly loops, signal-light cloverleafs) that keep traffic on the jam-free side of the Greenshield curve.
3. **Last-mile crowd connectivity** — a patent-pending road-wagon + level-platform system delivering light-rail-grade volumes at bus-grade infrastructure cost.

## Site

Single-page, static HTML — no build step, no dependencies.
- `index.html` — the entire site

## Deploy with GitHub Pages

1. Push this repo to GitHub.
2. Settings → Pages → Source: `main` branch, root folder.
3. Site goes live at `https://atif-hussain.github.io/CrowdGatherGo/`.
